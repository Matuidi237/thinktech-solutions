When you install Moodle for the first time, you discover a solid but sometimes austere platform. What many institutions don't know is that an official Marketplace lists over 2,000 free plugins, maintained by the global Moodle community. These extensions can deeply transform the user experience without touching a single line of code.

## What is the Moodle Marketplace?

The [Moodle Marketplace](https://moodle.org/plugins/) (formerly known as the Plugins Directory) is the official extension catalogue for Moodle. Each plugin is rated, reviewed, and its compatibility with different Moodle versions is clearly indicated. It is the first resource to check before commissioning any custom development.

## The most useful categories

### Activities and learning resources

Activity plugins enrich what you can offer learners. Among the most widely used:

- **H5P**: natively integrated since Moodle 3.9, it enables the creation of interactive content (quizzes, annotated videos, presentations) directly in the platform, with no external software needed.
- **Game**: turns standard Moodle quizzes into gamified activities, particularly appreciated in remedial training programmes.
- **Attendance**: a presence tracking module, useful for hybrid training where online sessions alternate with in-person ones.

### Visual themes

Moodle's appearance is fully customisable through themes. The default **Boost** theme is clean and responsive. Other themes such as **Moove** or **Classic** offer different layouts with configurable colours, logos, and banners — no CSS required.

For institutions that want a strong visual identity, we recommend Moove: it is well maintained, responsive, and its customisation options cover 90% of needs without additional development.

### Authentication and access

In the African context, two challenges come up repeatedly: managing large student cohorts and handling logins from shared devices. Plugins like **LDAP Authentication** or **OAuth2** centralise user accounts and eliminate the problem of multiple credentials.

For institutions without Active Directory infrastructure, the **Email-based self-registration** plugin with manual validation remains the simplest solution to deploy.

### Reporting and monitoring

Pedagogical tracking is a central issue. Moodle offers built-in reports, but they remain limited for quick reading by a course coordinator. The **Configurable Reports** plugin enables the creation of custom dashboards: completion rates by course, time spent per learner, grades by activity — all exportable to CSV or PDF.

## What we install on every deployment

On every platform we deploy, we enable by default:

1. **H5P** for interactive content
2. **Attendance** for hybrid training
3. **Configurable Reports** for pedagogical monitoring
4. **Moove** or a custom theme depending on the institution's identity

These four plugins address the most common needs without adding unnecessary weight to the platform.

## A word of caution on unofficial third-party plugins

The official Marketplace applies a minimum quality validation. Plugins shared outside this catalogue (forums, GitHub) may contain unmaintained code or versions incompatible with your Moodle instance. Our rule: only install plugins listed on moodle.org/plugins with at least one version compatible with the deployed release.
